# HoldsUp API

The FastAPI backend of HoldsUp: it extracts a numeric claim, matches it to an official
indicator, recomputes it with code and returns a verdict with a reproducible receipt.

This Space is generated by `make space-bundle` in the HoldsUp repository and replaced on
every deploy. Change the repository, not this Space. Routes are under `/v1` (try
`/v1/health`).
